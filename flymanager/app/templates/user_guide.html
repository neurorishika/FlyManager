FlyManager User Guide

Getting Started

Welcome to FlyManager! This guide will help you navigate and use the application effectively.

Important: The first step is to create an admin account. The admin account is required to configure the application and manage user access.

Authentication

Users must log in to access the system. If you are a new user, the admin can create an account for you. Alternatively, you can register yourself if the feature is enabled.

If you forget your password, use the "Forgot Password" option on the login page to reset it.

Features

  • Stock Management: Add, view, and manage genetic stocks, including their genotypes, tray positions, and statuses.
  • Cross Management: Create and manage genetic crosses, track their progress, and view predicted offspring genotypes.
  • Tray Management: Organize stocks and crosses into trays, visualize tray layouts, and manage tray occupancy.
  • Flip Schedule: Track and manage flipping schedules for stocks and crosses, ensuring timely maintenance.
  • Data Upload/Download: Upload data in bulk using Excel files or download existing data for analysis.
  • Label Generation: Generate labels for stocks and crosses for easy identification.
  • Bulk Operations: Perform bulk status updates and flipping operations for multiple items at once.

Usage Instructions

After logging in, navigate through the following modules:

  • Stock Explorer: Manage and explore genetic stocks.
  • Cross Explorer: Manage and explore genetic crosses.
  • Tray Management: Organize and manage trays for stocks and crosses.
  • Flip Schedule: View and manage flipping schedules.
