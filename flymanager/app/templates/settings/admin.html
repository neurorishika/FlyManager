This is the primary catalog refresh path for stocks, allele tables, phenotype tables, construct descriptions, and related FlyBase datasets.
FlyBase Gene Metadata Only

Refresh autocomplete gene metadata from the current local FlyBase stocks dump without redownloading the release bundle.

Use this when the FlyBase data files are already current and you only need to rebuild gene collections.
Phenotype Cache Backfill

Scan every user-owned stock and cross and backfill any missing or stale phenotype caches in one pass.

This is intended for bulk repair after phenotype cache changes or for importing older records that predate cached previews.
Force Full Recompute: Phenotype Cache

Rebuilds every stock and cross phenotype cache unconditionally, even entries that are already valid. Targeted rebuild (above) already covers routine edits and FlyBase refreshes automatically — use this only when the cached data itself is suspected wrong (e.g. after a bug fix to the phenotype predictor). Limited to once every 24 hours.
